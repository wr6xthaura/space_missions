# Space Missions

## Краткое описание
Консольное приложение на Python для просмотра и поиска информации о космических миссиях.

## Возможности
- Просмотр полного каталога космических миссий
- Поиск миссий по направлению 
- Вывод сообщения со списком доступных направлений, если миссии не найдены

## Структура проекта
| Файл          | Описание                                                   |
|---------------|------------------------------------------------------------|
| `main.py`     | Главный файл программы.                                    |
| `missions.py` | Файл с данными и функциями для их обработки.               |
| `README.md`   | Файл с кратким описанием программы и инструкцией к запуску |

- Запустите программу командой:
